## 手动维护与重新编译 `.tex`

需安装 TeX Live / MacTeX（支持 `xelatex` 与 `xeCJK`），连续执行三遍以收敛目录页码、书签与总页数：

```bash
xelatex -interaction=nonstopmode 泛函分析_二轮冲刺_重点速览与刷题自测版_v3.tex
xelatex -interaction=nonstopmode 泛函分析_二轮冲刺_重点速览与刷题自测版_v3.tex
xelatex -interaction=nonstopmode 泛函分析_二轮冲刺_重点速览与刷题自测版_v3.tex
```
